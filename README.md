# XAU Trader — releases

Installers for the XAU Trader desktop platform (Windows + Ubuntu/Debian) and its MetaTrader 5 Expert Advisor.
The app's built-in updater reads the releases of this repository.

- Windows: `XAUTrader-Setup-<version>.exe`
- Ubuntu / Debian: `xautrader_<version>_amd64.deb`
- MetaTrader 5 EA (manual install): `XAU-Trader-EA-v<version>.zip`
- `SHA256SUMS.txt`: checksums the updater verifies before installing
